# AI Primer: Agency Before Automation

A Brandeis Design and Innovation primer on generative AI for anyone who's curious, skeptical, or firmly against it. See how it works and what it costs, then make your own call on when to use it.

**Read it:** https://giannacrisha.github.io/agency-before-automation/

## What's inside

16 modules of about 20 minutes each. Every module has the same six parts: Learn, See, Try (always with a version that needs no AI account), Example, Your call, and Check.

| # | Module |
| --- | --- |
| 0 | Find your starting point |
| 1 | What AI is, and its kinds |
| 2 | How large language models work |
| 3 | Who uses it, and how |
| 4 | Limits, costs and open questions |
| 5 | Deciding whether to use it |
| 6 | Tools, privacy and opting out |
| 7 | Running AI on your own computer |
| 8 | Build your own offline sandbox |
| 9 | Prompting |
| 10 | Context and setting up a system |
| 11 | Workflows |
| 12 | Agents and loop engineering |
| 13 | Agentic programming |
| 14 | Teaching and policy |
| 15 | Your system and your boundaries |

## How it's built

One self-contained `index.html` with no build step and no dependencies beyond Google Fonts (Merriweather and Hind, the Brandeis digital typefaces). Checkmarks, ratings and the charter a reader writes stay in their own browser.

## Editing

Edit `index.html` and commit. GitHub Pages republishes the site automatically.
